# Консколькое приложеие, реализующее функционал формирования чека в магазине

Данное приложение генерирует чек для магазина. Учитывает предъявляемую карту и оптовые скидки.

## Возможности
- Персональной скидки
- Оптовые скидки при покупке от 5 единиц
- Чтение товаров и скидочных карт из CSV-файла
- Запись чека в CSV-файл
- Вывод чека в консоль
- Обработка исключений

## Запуск
  1. Клонируйте репозиторий

  2. Скомпилируйте проект с помощью вашей IDE

  3. Запустите основной класс `CheckRunner`

## Структура проекта
- `src/main/java/ru/clevertec/check` - основная логика приложения
    - `CheckRunner.java` - основной класс для запуска приложения
    - `Product.java` - класс для представления продукта
    - `Discount.java` - класс для представления дисконтной карты
    - `Check.java` - класс для представления чека
    - `CheckItem.java` - класс для представления позиции в чеке
    - `CreationCheck.java` - создания чека
    - `CheckReader.java` - утилита для чтения данных из CSV-файлов
    - `CheckSave.java` - утилита для записи чека в CSV-файл  
- `src/main/resources` - директория для хранения CSV-файлов
    - `products.csv` - файл с информацией о продуктах
    - `discountCards.csv` - файл с информацией о дисконтных картах
    - `check.csv` - файл для записи сгенерированного чека

После выполнения приложения, будет записан Results.csv в папку ./src/ и выведен чек в консоль.
